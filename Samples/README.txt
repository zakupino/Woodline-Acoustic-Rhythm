NO AUDIO SAMPLE FILES ARE INCLUDED IN THIS INITIAL SOURCE BUILD.

The current instrument sound is generated by its plucked-string DSP engine.

For a true sample + DSP hybrid production version, add only recordings that you own or are licensed to use. A useful recording plan is:

- Steel-string acoustic guitar, close microphone and room microphone perspectives.
- Six individual strings plus common open/barre chord voicings.
- Multiple velocity layers (soft, medium, hard) and at least 2–4 round robins per layer.
- Separate pick attack, fret/finger movement, string release and muted-strum recordings.
- Consistent tuning, sample rate, bit depth, start/end points and naming.
